# M4c2 — Selective original-texture character depth

2026-10-03. Technical rendering is implemented for **one upper-character cutout**, page 5 / panel 000 of the five supplied pages. Broad convincing full-character depth and the user's ≥4/5 depth/comfort assessment remain open. The other 29 masks are rejected; their panels retain flat original art and camera motion.

## Built

`pipeline/layers/publish.py` binds operator-selected, inspected candidates to source geometry, proof revision and exact candidate hashes. Changed sources, geometry, mask bytes or selection during compilation reject publication. Final/streamed MotionScript v2 attach the same layers. Snapshot preflight verifies source/mask hashes, PNG alpha and exact crop dimensions. No schema change was made.

`reader/src/character-layers.ts` shares the original page TextureSource and uses the PNG **alpha only**. Approved knots interpolate linearly inside the proved envelope; no extra tilt/rotation/offset is applied. Per-panel masks are released on navigation. Pause freezes poses; Parallax off, Reduce motion and original-page overview restore flat art. Missing/corrupt masks warn and disable only that layer. Streamed pages enable the previously unavailable depth control without overriding an existing user choice.

Cross-language transform hashing failed the first real publication because Python's `1.0` differs from JavaScript's `1`. Fixed with the shared consumer hash implementation; revision bumped and proofs rebuilt. Static/fixed comparison baselines now omit directed layers. Regression fixture copies include declared mask assets.
