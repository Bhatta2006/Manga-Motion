# M3d3 — Local scene music playback

2026-10-02. Technical implementation verified; device listening and story-quality gates remain open. Uses the explicitly approved v2 contract.

## Built

Final and streaming compilation now publish validated v2 scene beds. Immutable snapshots allowlist music/ambience/mask roles, verify actual bed SHA-256 and PCM duration/loop extent, and reject mutated bytes. Streaming retains earlier scene definitions. The full directed stream exactly matches final compilation in integration tests. Existing v1 chapters remain supported.

The Web Audio mixer has independent music, ambience, SFX and future voice controls. Sequential panels sharing a scene keep the same sources/loop phase. Scene changes crossfade with piecewise equal-power envelopes. Pause freezes phase; resume fades in; replay/back/nonadjacent seeks use the canonical scene offset with at least 50 ms fades. Shared incoming-transition calculations include page fades. Beds never set panel dwell. Silent Auto preserves timing and mute preferences. Missing/corrupt beds warn and allow camera reading to continue.

Only current-scene buffers are cached; retiring scenes finish their fades, with old retirements shortened on repeated navigation. Tested maximum: two decoded bed buffers and six live/retiring sources during rapid browser navigation; offline stress maximum four. No new model/download/cloud call. Unsupported character layers currently show an explicit flat-art warning; this is not character-depth delivery.
